## Cross-cutting risks

- **No version pinning anywhere.** `setup.py:49 install_requires` lists package names with no version bounds. `environment.yml` pins `python==3.11.8` and `openmm==8.3.1` only.
- **No GPU device selection.** Chai and Boltz claim whatever GPU is visible via `CUDA_VISIBLE_DEVICES`. With `num_threads > 1`, all worker threads compete for the same single device.
- **No timeouts on any subprocess call.** A wedged Vina/Squidly call hangs the whole run.
- **No retries.** Transient failures (AF2 fetch, network) abort the entry and its downstream.
- **Score scales not normalised.** Vina returns negative kcal/mol affinities; Boltz returns probabilities; Chai returns ptm/iptm in [0,1]; PLIP returns counts; the eventual best-structure selection in `add_metrics_to_best_structures` does not unify these scales â callers must interpret them per-column.
